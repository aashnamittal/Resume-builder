# Premium ATS-Friendly Resume Builder 📄✨

A sleek, interactive web application that allows users to instantly generate a professional, ATS-friendly resume in the classic Harvard/LaTeX academic format. Built entirely with vanilla HTML, CSS, and JavaScript.

## 🌟 Features

* **Live Interactive Preview:** Watch your resume build itself in real-time as you fill out the form.
* **Premium Glassmorphic UI:** A beautifully animated, deep navy-blue interface with 3D floating paper effects and smooth slide-in interactions.
* **Classic Academic Layout:** The output strictly adheres to the highly-respected, single-column Times New Roman aesthetic preferred by recruiters and ATS systems.
* **Dynamic Sections:** Easily add, remove, and manage multiple entries for Education, Projects, Leadership Experience, and Achievements.
* **Categorized Technical Skills:** Granular control over technical proficiencies (Languages, Frameworks, Developer Tools, and Coursework).
* **Auto-Formatting Bullets:** Seamlessly converts plain text descriptions into cleanly formatted bullet points.
* **Instant PDF Export:** Download a pixel-perfect, print-ready PDF of your resume with a single click (powered by html2pdf).

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and dynamic form generation.
* **CSS3:** Custom CSS variables, glassmorphism (`backdrop-filter`), CSS Grid/Flexbox, and advanced keyframe animations.
* **JavaScript (ES6):** DOM manipulation, event listeners, dynamic element generation, and live state rendering.
* **Libraries:** [html2pdf.js](https://ekoopmans.github.io/html2pdf.js/) for client-side PDF generation, FontAwesome for UI icons.

## 🚀 How to Use

1. **Clone or Download** the repository.
2. Open `index.html` in any modern web browser.
3. Fill out the beautifully animated form on the left side.
4. Review the live 3D-floating preview on the right.
5. Click **"Download PDF"** to instantly generate your professional resume!
